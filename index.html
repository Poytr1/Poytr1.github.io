A finding · arXiv, 2026

Does a language server save tokens for coding agents? Usually not.

Everyone says semantic retrieval is cheaper than grep; almost nobody measures it at equal task success. I defined one metric, tokens-to-success, ran a five-arm ablation on Python and TypeScript repositories across three Claude models, and the answer came out conditional and usually negative. The practical implication is not “always use LSP” but an adaptive router keyed on task class, model capability, and lexical noise.
